# 🏬 Store Rating App

A full-stack web application that allows users to view stores, rate them, and manage store data with role-based dashboards.

---

## 💻 Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JWT (JSON Web Tokens)

---

## 🔐 User Roles & Features

### 👤 Normal User
- Signup / Login
- View all stores
- Search by name/address
- Submit or update rating (1–5)

### 🧑‍💼 Admin
- Add new users (admin / normal)
- Add new stores
- View dashboard stats (total users, stores, ratings)

### 🏪 Store Owner
- View customers who rated their store
- View average rating of their store
